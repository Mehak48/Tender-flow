# Test plan

What is tested, how, and the latest real results. Tests use only **fictional** documents generated by
`backend/tools/sample_docs.py`; no real tender or quotation is committed.

## 1. Levels

| Level | Tool | Scope |
|---|---|---|
| Unit | pytest | Normalisation (dates, durations, numbers, currency), parsers, template analysis, arithmetic, AI guards |
| Integration / API | pytest + FastAPI `TestClient` (temporary data directory per test) | Every route the UI uses, end-to-end through the real pipeline |
| Frontend unit / component | Vitest + Testing Library (jsdom) | Formatting, file checks, router, API client, UploadSlot, DocField, InstructionPanel |
| End-to-end | Playwright script `scripts/e2e_demo.cjs` (Chromium) | The demo journey in a real browser against the built app; fails on any console error (including CSP violations) |
| Static | ruff, ruff format, mypy · ESLint, `tsc --noEmit` | Style, bugs, types |
| Supply chain / secrets | `npm audit`, `scripts/check_secrets.py` | Known-vulnerable packages, committed secrets |

## 2. Fixtures (all fictional)

Built once per test session (`tests/conftest.py` → `docs` fixture):

- Tenders: network-equipment tender as **PDF** and **DOCX** (with a deliberate deadline conflict), a tender with no
  deadline, a **malicious** tender with instruction-like text, a minimal tender, a blank PDF and a scanned
  (image-only) PDF.
- Templates: DOCX with placeholders + label blanks + items table, DOCX with `{{item.*}}` placeholder rows, DOCX
  without an items table, XLSX template.
- Price lists: XLSX and CSV (no price for the 42U rack on purpose; several names match only partially and need
  confirmation).
- Generated in tests: fake/oversized/empty files, zip-bomb-like containers, "billion laughs" XLSX and DOCX.

## 5. End-to-end journey (14 steps)

1. Overview loads; backend connected. 2. Sample tender parsed: reference extracted, deadline conflict shown.
3. Conflict resolved by choosing a candidate. 4. All found values confirmed, including the needs-review address.
5. Mapping step shows template fields. 6. Quotation generated; editor and the *In your template* preview render.
7. Instruction previewed; *Apply* disabled until the material change is confirmed; applied. 8. Missing price
entered; amount recalculated. 9. Quick fixes (currency, matched prices, terms). 10. Warnings acknowledged →
*Ready to export*. 11. DOCX exported, previewed and downloaded; the file is a valid DOCX. 12. Real uploads of a
DOCX tender and an XLSX template through the file inputs. 13. PNG rejected with an explanation.
14. *My work* and *Settings* render.

## 6. Requirement → test traceability (key rules)

| Rule from the brief | Evidence |
|---|---|
| Never invent tender data | `test_missing_fields_stay_missing`, `test_minimal_tender_reports_gaps`, `test_extraction_never_marks_values_as_confirmed` |
| Never invent prices / tax / currency | `test_generated_quotation_uses_only_supplied_values`, `test_missing_price_means_no_total`, `test_tax_is_only_applied_when_configured`, `test_guards_drop_invented_numbers_and_unknown_items` |
| Deterministic arithmetic | `test_line_amounts_subtotal_and_total_use_decimal`, `test_money_rounding_and_formatting`, `test_arithmetic_mismatch_and_quick_fix` |
| Documents are data, not instructions | `test_document_instructions_do_not_change_behaviour`, `test_ai_fallback_through_the_api` |
| Material changes need confirmation | `test_material_changes_need_confirmation_then_apply_and_undo`, E2E step 7 |
| Signature never filled | `test_docx_template_fields_and_items_table` (not required), `test_docx_export_contains_the_quotation` (`Signature: ____` stays blank) |
| Original template unchanged | `test_final_export_is_blocked_until_ready_but_draft_is_allowed` (export check "Original template file unchanged") |
| No paths / secrets in responses | `test_uploads_are_stored_under_generated_ids`, `test_health_reports_capabilities_without_secrets`, `test_status_never_exposes_the_key` |
| Unsupported features disabled honestly | `test_pdf_unavailable_is_reported_honestly`, `test_blank_and_scanned_pdfs_are_reported_not_invented` |

## 8. How to run

```bash
# backend (from backend/, virtualenv active, requirements-dev installed)
python -m pytest            # 96 tests
ruff check . && ruff format --check . && mypy app

# frontend (from frontend/)
npm test && npm run lint && npm run typecheck && npm run build && npm audit

# end-to-end (repository root; see the script header for prerequisites)
#   terminal 1: cd backend && TENDERFLOW_DATA_DIR=/tmp/tf-e2e uvicorn app.main:app --port 8765
BASE_URL=http://127.0.0.1:8765 node scripts/e2e_demo.cjs

# secrets
python scripts/check_secrets.py
```

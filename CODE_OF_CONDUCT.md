# Code of Conduct

This is a project-specific code of conduct written for TenderFlow. It is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/), but it is not the Contributor Covenant text. Teams
that prefer the official text can replace this file with it (it is licensed CC BY 4.0 and requires attribution).

## Our commitment

We want TenderFlow to be a welcoming project for everyone, regardless of background, identity, experience level,
nationality, religion, disability, age, gender or appearance.

## Expected behaviour

- Be respectful and patient, especially with people who are new to open source.
- Give and accept constructive feedback about code and ideas, not about people.
- Assume good intent, ask questions before drawing conclusions.
- Credit other people's work and respect licences.
- Protect privacy: never share someone's personal data or a confidential document in issues, pull requests or chats.

## Unacceptable behaviour

- Harassment, insults, discriminatory jokes or language, and personal attacks.
- Sexualised language or imagery.
- Publishing others' private information without permission.
- Sustained disruption of discussions or deliberately misleading contributions.

## Enforcement

Report problems privately to the maintainers (add the team's contact address here before publishing). Reports are
handled confidentially. Maintainers may remove comments or contributions and may temporarily or permanently block
participants who break this code of conduct. Decisions are explained to the people involved where possible.

## Scope

This code applies in all project spaces — the repository, issues, pull requests, chats and events — and when
someone represents the project in public.
